04 · Technical Inquiry

Integration and sovereign deployment.

Frequently addressed engineering specifications for developers integrating Kilnwave into audio DAWs, hardware DSPs, and sovereign LLM pipelines.

How does Kilnwave prevent phase cancellation when modifying isolated bands?
By predicting continuous phase differentials along instantaneous frequency trajectories rather than quantizing into rigid FFT frames, the resynthesis engine reconstructs exact wave continuity at the crossover boundaries, yielding zero comb filtering.
Can Kilnwave run entirely on-premise or air-gapped?
Yes. The inference core compiles to static C++20 dynamic libraries and CUDA/Metal shaders with zero external network phone-homes, making it 100% compliant with sovereign security and air-gapped studio requirements.
What hardware acceleration is supported?
Kilnwave ships native bindings for NVIDIA TensorRT (Ampere and newer), Apple Silicon Metal Performance Shaders (M-series), and AVX-512 vector CPU fallback for zero-GPU environments.
What audio sample rates and bit depths are natively handled?
Standard support spans 44.1kHz, 48kHz, 96kHz, and 192kHz uncompressed PCM at 24-bit and 32-bit floating point, with dynamic block sizes from 16 to 1024 frames.
